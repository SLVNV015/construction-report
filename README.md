# Журнал операций на стройке

Веб-приложение для учета строительных операций с CRUD функционалом и фильтрацией.

## Быстрый старт

### Предварительные требования

- Docker
- Docker Compose
- Make (опционально)

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone git@github.com:SLVNV015/construction-report.git
cd construction-report
```

2. Скопируйте файл с переменными окружения:
```bash
cp .env.example .env
```

3. Соберите и запустите проект:
```bash
make build
make up
```

Или без Make:
```bash
docker-compose build
docker-compose up -d
```

4. Откройте в браузере:
- **Веб-интерфейс**: http://localhost
- **API**: http://localhost:3000/api
- **Swagger**: http://localhost:3000/api/docs

## Технологии

### Архитектура

- **NX Монорепо** — позволяет переиспользовать типы и схемы валидации между фронтендом и бэкендом, избегая дублирования кода и рассинхронизации контрактов

### Бэкенд

- **NestJS** — фреймворк с встроенным DI-контейнером и декораторами, что упрощает управление зависимостями и структурирование кода
- **TypeORM** — ORM с поддержкой TypeScript и декларативного описания сущностей (альтернатива — Prisma, но TypeORM лучше интегрируется с NestJS)
- **PostgreSQL** — надежная реляционная БД для хранения операций
- **Webpack** — бэкенд собирается в единый бандл для упрощения деплоя

### Валидация

- **Zod** — общая схема валидации для фронтенда и бэкенда, более удобный API по сравнению с class-validator, лучшая типизация

### Фронтенд

- **React + Vite** — быстрая сборка и HMR, без избыточности Next.js для простого SPA
- **Tailwind CSS** — utility-first подход для быстрой стилизации
- **Интерфейс в стиле 1С** — желто-белая цветовая схема для привычного восприятия пользователями
- **Генератор тестовых данных** — функционал для добавления случайных записей, чтобы не заполнять вручную

### Инфраструктура

- **Docker + Docker Compose** — изолированное окружение для всех сервисов
- **Nginx** — веб-сервер для раздачи статики фронтенда и проксирования API-запросов

## Функционал

- CRUD операций на стройке
- Виды работ (предзаданные + возможность добавления своих)
- Объем работ с единицами измерения
- Фильтрация по датам, работникам, видам работ
- Интерфейс в стиле 1С (желто-белая цветовая схема)

### Makefile команды

```bash
make help       # Показать все доступные команды
make build      # Собрать Docker образы
make up         # Запустить все сервисы
make down       # Остановить все сервисы
make restart    # Перезапустить все сервисы
make clean      # Остановить и удалить контейнеры, сети и volumes
```

## Структура проекта

```
construction-report/
├── api/                      # NestJS бэкенд
│   └── src/
│       └── app/
│           ├── entities/     # TypeORM сущности
│           ├── dto/          # Zod валидация
│           ├── services/     # Бизнес-логика
│           ├── controllers/  # REST API endpoints
│           └── pipes/        # Валидация пайпы
├── web/                      # React фронтенд
│   └── src/
│       ├── api/              # API клиент
│       ├── components/       # React компоненты
│       └── app/              # Главный компонент
├── packages/                 # Shared общие типы и схемы
│   └── src/
│       ├── index/            # экспорты
│       ├── schemas/          # схемы zod 
│       └── types/            # общие типы
├── dockerfile.api            # Dockerfile для бэкенда
├── dockerfile.web            # Dockerfile для фронтенда
├── docker-compose.yaml       # Docker Compose конфигурация
├── nginx.conf                # Nginx конфигурация
├── Makefile                  # Make команды
├── .env                      # Переменные окружения
└── .env.example              # Пример переменных окружения
```
